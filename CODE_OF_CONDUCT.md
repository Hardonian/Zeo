# Code of Conduct

## Our commitment

We are committed to creating a respectful, inclusive, and constructive community for contributors of all backgrounds and experience levels.

## Expected behavior

- Communicate with professionalism and empathy.
- Prefer evidence-backed discussion over authority claims.
- Give and receive feedback constructively.
- Focus on ideas and implementation details, not personal attributes.

## Unacceptable behavior

- Harassment, intimidation, threats, or discrimination.
- Personal attacks, trolling, or sustained disruption.
- Publishing private information without consent.
- Sexualized language or unwelcome advances.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with these standards.

## Reporting

To report behavior that violates this Code of Conduct, contact maintainers via repository maintainership channels. For security-sensitive matters, use `SECURITY.md`.

## Scope

This Code of Conduct applies in project spaces (issues, pull requests, discussions, and reviews) and in public spaces where someone is representing the Zeo project.
