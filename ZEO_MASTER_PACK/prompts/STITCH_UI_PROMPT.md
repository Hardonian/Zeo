# ZEO – Stitch UI System Prompt

Design a premium dark-mode enterprise SaaS UI for **ZEO** (AI decision intelligence engine).

**Palette:** deep navy base, electric blue highlights, subtle gold accents
**Style:** minimal, infrastructure-grade, strong hierarchy, accessible contrast (WCAG AA), low visual noise

## Pages / Panels
1) **Dashboard Overview**
- System State
- Active Constraints
- Scenario Simulation module
- Outcome comparison grid
- Risk heatmap

2) **Simulation Studio**
- Left: constraints inputs
- Center: scenario builder
- Right: projected outcome metrics + charts

3) **System Map**
- Network graph visualization
- Node health/status indicators
- Expandable dependency tree

4) **CLI View**
- Refined terminal styling
- Structured output blocks
- Clean typography

Goal: feels like enterprise infrastructure, not “startup dashboard.”
