## Integration

Panels are served via the `/stitch/[slug]` route using iframe sandboxing. The `stitch.ts` library handles:
- Dynamic discovery of all panels
- Category organization
- Static generation of routes
- Safe iframe rendering with `sandbox="allow-scripts allow-same-origin"`

## Route Generation

Routes are automatically generated from panel directory names using the `slugify` function:
- Converts to lowercase
- Replaces `&` with "and"
- Replaces non-alphanumeric with hyphens
- Trims leading/trailing hyphens

Example: `bias_inspector_&_counterweights` → `bias-inspector-and-counterweights`
