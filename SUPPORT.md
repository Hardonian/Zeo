# Support Policy

Thank you for using Antigravity! We are committed to providing operator-grade support.

## Getting Help

1.  **Doctor First**: Before reaching out, please run `pnpm doctor` and attach the output to your request.
2.  **Documentation**: Check the [Docs](./docs/) folder for guides on setup, policies, and troubleshooting.
3.  **GitHub Issues**: For bugs and feature requests, please use our [Issue Templates](.github/ISSUE_TEMPLATE/).

## Operational Support

For critical production issues, including:
- Webhook delivery failures
- Determinism violations in evidence bundles
- System outages

Please email `ops@hardonian.com` with:
- Organization ID
- Repository ID
- Affected Commit SHA
- Trace ID from logs (if available)

## Community

Join our Hardonian Discord for architectural discussions and community-driven policy packs.
