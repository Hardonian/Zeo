DR-01: Production Dry Run Enforcement

check_circle

Status: Active

error

Violation Detected

Description

To ensure stability and prevent accidental outages, all runbooks targeting production environments must successfully complete a dry run before full execution. This prevents destructive commands from running without verification.

Enforcement Level

lock_clock

Hard Block / Required Step

Execution is prevented until all conditions are met.

auto_fix_high

How to Fix

1

Click the "Dry Run" button in the header toolbar.

2

Review the predicted side effects in the output console.

3

Proceed to execution once the check passes and the "Execute" button is enabled.
